## Bash Scripting : 
programming a bash script is called bash scripting.
Bash Script contains sequence of commands that are executed by bash program line by line.

## Adavantage
- Automation
- Portability : shell script can run on various platform and OS including linux, Unix, macOS
- Flexibility : shell script can easily be modified
- Accessibilty : Easy to access shell script, not require additonal tool
- Integration : shell script can intergrate with other tool & application like DB, web server, cloud, etc
- Debugging : easy to debug
